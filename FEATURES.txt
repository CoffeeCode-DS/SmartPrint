================================================================================
                         SMARTPRINT SYSTEM - COMPLETE FEATURES
================================================================================

1. KIOSK & MULTI-USER WORKFLOW
--------------------------------------------------------------------------------
* Persistent Kiosk QR Code:
  - The QR code on the kiosk screen remains active and persistent.
  - Multiple users can scan the exact same QR code from their mobile devices
    simultaneously without locking each other out.
  - Generates dedicated user sessions automatically upon scan.
* Automatic Device Authentication:
  - Users scanning via mobile are automatically authenticated with a secure
    session token without requiring manual password entry.
* Real-Time Synchronization:
  - WebSockets (Socket.IO) synchronize file uploads, print queue status, and
    printer status in real time across kiosk, operator dashboard, and mobile devices.


2. DOCUMENT UPLOAD & SECURITY
--------------------------------------------------------------------------------
* High Capacity Upload Limit:
  - Upload file size limit expanded to 100 MB per file (enforced both at Multer
    middleware layer and file service layer).
* Comprehensive Format Support:
  - PDF Documents (.pdf)
  - Microsoft Word Documents (.docx and .doc)
  - Images (JPEG, JPG, PNG)
* Deep Binary Magic-Byte Inspection (Anti-Spoofing):
  - File extension alone is never trusted.
  - Verifies binary header signatures:
    * .docx: PKZip signature [0x50, 0x4B, 0x03, 0x04]
    * .doc:  CFBF / OLE signature [0xD0, 0xCF, 0x11, 0xE0, 0xA1, 0xB1, 0x1A, 0xE1]
    * .pdf:  PDF header [%PDF-]
    * .png:  PNG signature [0x89, 0x50, 0x4E, 0x47, ...]
    * .jpg:  JPEG SOI marker [0xFF, 0xD8, 0xFF]
* Content Hashing & Deduplication:
  - SHA-256 checksum calculated for every uploaded file.
  - Automatically identifies duplicate uploads and links them cleanly.
* Filesystem Sandboxing:
  - Filenames are sanitized and renamed to secure cryptographic hashes on disk.
  - Directory traversal attacks are prevented using strict path confinement.


3. AUTOMATIC POST-PRINT DELETION & CUSTOMER PRIVACY
--------------------------------------------------------------------------------
* Zero-Retention Privacy Policy:
  - Customer files are treated as strictly temporary.
* Automatic Post-Print File Deletion:
  - Once a print job successfully finishes (PRINT_JOB_COMPLETED), a 15-second
    grace timer begins (allowing the OS print spooler to finish).
  - The raw document bytes are securely deleted/unlinked from the disk storage.
  - Database status is updated to 'DELETED'.
  - A real-time WebSocket 'file:deleted' event is broadcast to all clients.
  - Complete audit log entry recorded (FILE_AUTO_DELETED_POST_PRINT).
* Error Protection (Failure Safety):
  - If a print job fails, the file is NOT deleted.
  - The customer or operator can easily click "Retry" or "Change Printer" without
    having to re-upload the document.


4. REAL WINDOWS PRINTER HARDWARE INTEGRATION
--------------------------------------------------------------------------------
* Native Windows Spooler Discovery:
  - Interacts directly with Windows Print Management via PowerShell CIM (WMI)
    and .NET System.Drawing.Printing.
  - Discovers all physical, virtual, and network printers installed on Windows.
* Hardware-Level Capabilities Detection:
  - Detects whether the printer supports Color or is strictly Monochrome/B&W.
  - Detects hardware Duplex capability (2-sided printing).
  - Queries exact supported Paper Sizes (A4, A3, Letter, Legal, etc.).
  - Reads maximum supported copies per job.
* Real Printer Status Monitoring:
  - Real-time status mapping: READY, BUSY, PRINTING, PAUSED, ERROR, OFFLINE.
  - Live status indicator dots in the UI.
* Native Test Page Printing:
  - Directly calls Win32_Printer PrintTestPage() method via WMI to test
    physical printer communication.
* Network Printer Setup:
  - Ability to add network IP printers via automated Standard TCP/IP Port configuration.


5. ADVANCED PRINT DOCUMENT DIALOG & PREVIEW
--------------------------------------------------------------------------------
* Modern Native-Style Print Dialog:
  - Retains clean kiosk design with seamless controls.
  - Dynamic printer selection list displaying real printer names and live status.
  - Dynamic capability locks:
    * If printer is monochrome, Color option is automatically disabled.
    * If printer cannot duplex, 2-sided option is disabled.
    * Paper size dropdown only displays sizes supported by that specific printer.
* Interactive Document Preview:
  - Multi-page document navigation (Page X of Y, Previous / Next buttons).
  - Zoom controls (Zoom Out, 100% Reset, Zoom In).
  - Live Black & White preview filter (CSS grayscale rendering).
  - Live Orientation toggle (Portrait vs. Landscape preview rotation).
  - Microsoft Word document dedicated preview card.
* Detailed Print Options:
  - Copies counter (- 1 +).
  - Page Range Selection:
    * All Pages
    * Current Page
    * Custom Page Range (e.g., '1-3, 5, 8-10' with real-time format validation).
  - Color Mode: Color vs. Black & White.
  - Duplex / 2-Sided Printing: Off (1-sided), Flip on Long Edge, Flip on Short Edge.
  - Pages Per Sheet (N-Up): 1, 2, 4, 6, 9, 16 pages per sheet.
  - Scaling: Fit to Printable Area, Actual Size, Shrink Oversized Pages, Custom %.
* In-Dialog Real-Time Job Progress:
  - Live progress bar showing spooling and printing progression.
  - Success banner upon completion.
  - Detailed error reporting on failure with 1-click "Retry" and "Change Printer".


6. OPERATOR DASHBOARD & QUEUE MANAGEMENT
--------------------------------------------------------------------------------
